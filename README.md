### About me

My projects range from training agents to play games to building tools that analyze network traffic and reconcile transactions. I work across Python, JavaScript, and TypeScript, with C, C++, and Go also in my toolkit.

- **Machine learning:** reinforcement learning and network traffic classification.
- **Backend systems:** APIs, event streaming, and data processing.
- **Web applications:** dashboards that make complex data easier to explore.
